# 📂 Documentación (docs/)

Este directorio está dedicado a almacenar toda la documentación técnica, teórica y procedimental del proyecto. 

## Archivos Principales
*   **Microproyecto Robótica**: Documento principal del proyecto con las directrices generales.
*   **anteproyecto_herramienta.md**: Propuesta de investigación detallando el problema de la metrología de grietas, justificación, hipótesis y estado del arte.
*   **Protocolos de calibración**: Documentos que describen los procedimientos en el banco de pruebas micrométrico para garantizar la repetibilidad y reproducibilidad (R&R).

## Notas para el equipo
Mantengan esta carpeta actualizada con diagramas de arquitectura, minutas de reuniones y manuales de usuario. Si agregan imágenes o diagramas, procuren crear una subcarpeta `img/` aquí dentro.
