# 🧪 Pruebas y Validación (tests/)

Este directorio contiene todos los scripts destinados a asegurar la calidad del software y la precisión metrológica del hardware.

## Contenido
*   **Pruebas unitarias**: Scripts para verificar que funciones matemáticas aisladas en `src/` funcionen correctamente (ej. validación matricial del Filtro de Kalman Extendido).
*   **Validación de Hardware**: Scripts para verificar la sincronización determinista basada en sellos de tiempo y el cálculo de latencia.
*   **Pruebas de R&R**: Scripts para procesar estadísticamente los datos de las pruebas de repetibilidad y reproducibilidad en el banco micrométrico.
